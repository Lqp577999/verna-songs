创建私密管理书签

首次需要仓库拥有者设置授权，以后从私密书签进入即可管理。

  1. 在 GitHub 的 Settings → Developer settings → Personal access tokens → Fine-grained tokens 创建专用令牌。Resource owner 选择 Lqp577999，Repository access 仅选择 verna-songs。
  2. Repository permissions 将 Contents 设为 Read and write；Metadata 使用默认只读。设置合适的有效期。此权限可以写所选仓库内容，不能限制为仅写 catalog.json；不要授权其他仓库或复用其他网站令牌。
  3. 仅在下面的本地浏览器表单输入令牌。此设置页不发起网络请求。生成的完整链接相当于钥匙，勿发送给他人、对话或截图；浏览器同步书签也可能将它上传到自己的浏览器账号。

私密链接已在此浏览器中生成

先复制下面的完整链接并保存到安全的密码管理器或书签，再打开。管理页面会立即移除地址中的钥匙；进入后直接收藏地址栏不会包含授权。

打开管理页

链接泄露时立即在 GitHub 撤销对应令牌，重新生成独立令牌并替换私密书签。授权过期时执行同样的轮换。普通访客可查看管理页静态文件，但没有令牌无法写入。
